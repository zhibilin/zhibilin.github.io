# 认识C4d

- C4dD全名CINEMA 4D，德国MAXON公司推出的3D动画软件
- 常用的三维软件包含C4D，3DsMax，Maya，Blender
- C4D被广泛用于视觉设计与影视制作中，其中在国内视觉设计中以电商部分所占比例最多

### 选择工具

- 移动对象需要将鼠标放置在轴上，轴变白色后方可移动，如果鼠标放置在州外即随意移动（慎用），
放在两个轴之间的三角形可在两个轴上移动

- 常用快捷键
  - `E` 移动  可配合`Shift`使用
  - `R` 旋转  可配合`Shift`使用
  - `T` 缩放  可配合`Shift`使用


- 对象丢失可以通过选择对象，按`O键`最大化显示找到对象
- 按住`Ctrl`键移动对象即可复制对象、在对象面板中按住  `Ctrl`键移动对象即可原位复制对象
- 快捷键
  - `9` 实时选择工具
  - `0` 框选工具
  - `鼠标中键` 控制范围大小
  - `Ctrl+Z` 撤销
  - `Ctrl+Y` 重做
  - `Shift+G` 取消群组    需要在对象面板选中最上层的组文件夹
  - `alt+G`   建立群组

##   命令父子级关系

**父子级命令的区分**

比如以  圆柱体A 为目标对象

父级命令（绿色）：如挤压、旋转等命令，要使他生效，需要在对象面板将A拖入这些父级命令的子目录
子级命令（紫色）：如弯曲、扭曲、网格等命令，要使他生效，需要在对象面板将这些子级命令拖入的A子目录
